# Typefaces for the Word export

One TrueType face per family the built-in themes use, embedded in the .docx so
the document opens in its own type on a machine that does not have it. Every
family here is published under the SIL Open Font License 1.1, which permits
bundling and embedding:

| File                    | Family           |
| ----------------------- | ---------------- |
| Archivo-700.ttf         | Archivo          |
| IBMPlexSans-400.ttf     | IBM Plex Sans    |
| IBMPlexSerif-400.ttf    | IBM Plex Serif   |
| Inter-400.ttf           | Inter            |
| Merriweather-700.ttf    | Merriweather     |
| PlayfairDisplay-700.ttf | Playfair Display |
| SourceSans3-400.ttf     | Source Sans 3    |
| SourceSerif4-400.ttf    | Source Serif 4   |
| SpaceGrotesk-400.ttf    | Space Grotesk    |

The licence text travels with each family at https://fonts.google.com. A theme a
host registers with another family simply has no face here, and Word
substitutes.
