# PLAN_COPILOT_FINDINGS: what the 2026-10-08 review of the AI established

The verified findings of the 2026-10-08 review of wb-fastr-v2's AI: the product
copilot, the HFA indicator assistant and `/mcp`. Nine code inventories were each
checked by an adversarial verifier, and six review lenses then read a draft of
the proposal against the code. Every correction the verifiers and the lenses
made is applied here. This file is the fixed reference of the COPILOT program
(panther's `PLAN_COPILOT_ORCHESTRATION.md`, ruling R8):
`PLAN_COPILOT02_FIXES.md` and `PLAN_COPILOT03_ONE_CHAT.md` cite its entries by
ID instead of restating them.

- No session edits this file. A plan session edits only its own plan's **Next
  step** line and build log (the two-things rule,
  `panther/protocols/PROTOCOL_ALL_PLANS.md`).
- Where this file and the code disagree, the code wins, and the session records
  the disagreement in its plan's build log.
- The session that deletes `PLAN_COPILOT03_ONE_CHAT.md` deletes this file in the
  same commit.
- Checked against branch `version2` at `4d6d6050b`. Its code is identical to
  `af76a7dbe`, where the inventories ran: the one commit between them changes
  only `PLAN_IMPORT_FEEDBACK.md`. Line numbers are as of `dba8b7887`.
- The chat engine itself is panther's `DOC_AI_CHAT.md`, and
  `PLAN_COPILOT01_ENGINE_FINDINGS.md` until G1 opens. Section C lists only the
  engine facts the app meets.
- IDs: places A01 to A60, tools B01 to B57, engine facts C01 to C29, defects D01
